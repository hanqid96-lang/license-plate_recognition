# 基于STM32F429利用深度学习的车牌本地识别系统
本项目实现一套**端侧深度学习车牌识别系统**，完全基于本地运行，无需联网，针对安徽省蓝底车牌格式优化，可在自主打板的STM32F429开发板上完成图像采集、预处理、推理与结果输出，适用于嵌入式学习、智能门禁及车载识别等场景的技术探索。

## 项目核心亮点
- **硬件平台**：采用STM32F429IIT6主控芯片，自主设计并打板最小系统，搭配OV5640摄像头模块实现图像采集，扩展SDRAM用于缓存海量图像数据与模型推理，满足端侧计算需求。
- **数据与训练**：训练数据完全基于开源**CCPD (Chinese City Parking Dataset)** 数据集，感谢原作者在ECCV 2018分享的大规模标注数据。通过`cut.py`完成车牌定位、字符切片预处理，提取高质量训练样本；利用`practice.py`基于深度学习框架训练CNN字符识别模型，生成模型权重。
- **端侧部署**：将Python训练的模型权重转换为C语言头文件格式，无缝集成至STM32 Keil工程。系统上电后，OV5640实时采集车牌图像，经预处理后调用本地模型推理，最终输出车牌字符结果。

## 项目现状与优化
目前系统可稳定识别**清晰、正对**的安徽省蓝底车牌，完成端侧识别全流程。但在复杂场景下（如逆光、模糊、倾斜、污损车牌），识别精度和鲁棒性仍有提升空间，需进一步优化模型与算法。
